# Versions are pinned exactly, and that is a deliberate choice rather than
# caution for its own sake. These are the versions every figure in the README
# was produced with. An earlier unpinned build resolved to scikit-learn 1.9 and
# moved the reported unseen-merchant accuracy from 3.5% to 11.5% - a documented
# result silently changing underneath the document. A model repository whose
# numbers depend on the day you installed it cannot be reviewed.
#
# To move the floor: bump a pin, run `make pipeline`, and check the figures in
# README.md and docs/ still match reports/metrics.json.
